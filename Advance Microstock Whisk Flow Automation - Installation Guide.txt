ADVANCE MICROSTOCK – WHISK / FLOW AUTOMATION
CHROME EXTENSION INSTALLATION GUIDE

BEFORE YOU START
1. Download the ZIP file from the Advance Microstock website.
2. In Windows, right-click the ZIP file and choose "Extract All...".
3. Choose a permanent folder and extract the files.
4. Keep the extracted folder in that location. Do not delete or move it after installation.

INSTALL IN GOOGLE CHROME
1. Open Google Chrome.
2. In the address bar, enter: chrome://extensions
   This opens Manage Extensions.
3. Turn ON "Developer mode" using the switch near the top-right corner.
4. Click "Load unpacked".
5. Browse to the folder where you extracted the ZIP.
6. Select the folder that contains manifest.json directly, then click "Select Folder".
   IMPORTANT: Do not select the ZIP file. Do not select a parent folder if manifest.json is inside a folder below it.
7. The Advance Microstock – Whisk / Flow Automation extension should appear in Chrome.
8. Open flow.google.com or labs.google and use the extension from Chrome's Extensions menu.
9. You may pin the extension to the Chrome toolbar for easier access.

HOW TO UPDATE THE EXTENSION
1. Download the latest ZIP file and extract it.
2. Open chrome://extensions.
3. Find Advance Microstock – Whisk / Flow Automation and click its Reload button.
4. If you extracted the new version into a different folder, use "Load unpacked" to select the new folder, then remove the old copy if you no longer need it.
5. Refresh the Whisk / Flow browser tab.

TROUBLESHOOTING
- If "Load unpacked" is missing, make sure Developer mode is ON.
- If Chrome says manifest.json is missing, select the folder that has manifest.json directly inside it.
- Keep the extracted extension folder on your computer. Chrome loads the extension from that folder.
